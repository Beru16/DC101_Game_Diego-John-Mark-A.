# DC101_Game_Diego-John-Mark-A.
Rock Paper Scissor Game- A simple interactive **Rock–Paper–Scissors** browser game where the player competes against the computer. The computer randomly selects Rock, Paper, or Scissors — and the score updates automatically after each round.
Technologies Used- HTML  CSS   JavaScript  
Download or clone this repository
 Open `index.html` in your browser
 Click **Rock, Paper, or Scissors** to play
